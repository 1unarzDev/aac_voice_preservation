# Oracle on real outputs and baseline oracles: plan (written before any judge call)

Answers the two remaining SE4All objections: (1) oracle mutation testing used clean authored sentences; (2) no baseline oracle.

## Finding about W-A mutation code
W-A mutants were hand-written, one per source (`analysis/oracle/source_mutations.jsonl`), not generated by code. There is no operator code to reuse.
We therefore implement the SAME operator families as deterministic functions (`src/oracle_real_ops.py`), one family per dimension, each scoped
so the critical value flips: negation insertion/removal (polarity); speech-act flip question<->statement, request->statement (speech_act);
agent swap I<->you (agent); certainty hedge/booster insertion, hedge removal (certainty); politeness add/remove (politeness);
time shift past/now/later (time_quantity). Operators that do not apply to a sentence return None (that sentence is skipped; applicability is reported).

## Task A design
- Pool: `runs/hw1/scored.parquet` rows with valid output, channel in {chip1, chipall, full} (cue given, so a preserved commitment is real),
  critical_match True with critical_source in {agree, arbiter} (judge critical = the reference value), refusal/acceptance quarantine off.
  One output per family and per distinct text (seeded pick).
- Seed 20261102. Draw order = seeded shuffle per dimension; walk the shuffled pool, take the first N sentences the operator can mutate.
  Quota: 200 mutants over 6 dimensions (34,34,33,33,33,33 in alphabetical order). Applicability rate per dimension is reported.
- Controls: 100 meaning-preserving surface edits, separate seeded draw from the same pool, from families not used for mutants, quotas 17x4+16x2.
  Edit types (declared, no paraphrase): contraction toggle (n't, 'm, 're, 'll, cannot), punctuation (drop final period; drop commas),
  synonym swap from a fixed lexicon of 16 non-critical nouns/verbs/adjectives (no critical-cue word is in it). Types are rotated for balance.
- Judge: production `judge.py` (J1+J2, gpt-6.1-sol, effort low), concurrency 4, items built like W-A (`runs/oracle_real/`). A mutant is "caught" when
  critical_match(dim, reference value, judge critical) is False (production rule, incl. the certainty plain~emphatic tolerance). J1!=J2 critical
  rows: arbiter if few, else bounds (unresolved counted as caught / as missed).
- Metrics: mutation score = caught / mutants by operator and dimension (Wilson 95%); false-alarm rate on controls; also the exact-expected-label rate.
  Plain-assertion + booster mutants ("definitely") are tolerated by the production contract (plain is honoured by emphatic); they are reported
  as a separate row and EXCLUDED from the headline mutation score (1 in 4 of plain-certainty sources get a booster, hash-chosen).
- Comparison with W-A: injection_results.csv (120 identity / 120 mutants) and challenge_results.csv.

## Task B baselines (deterministic, `src/oracle_baselines.py`)
(i) Surface oracle: per dimension regex/lexicon labeler (negation tokens; "?"/request/offer forms; pronoun person; hedge/booster lexicon;
please/thanks/sorry/could-you; tense and time words; number words for quantity) then the same critical_match as the judge.
(ii) String-overlap oracle: pass iff the output contains a token unique to the reference variant's source relative to its minimal-pair partner
(the "critical surface form", privileged key information so it is a generous baseline); if the reference variant has no unique token, pass iff the output
contains none of the partner's unique tokens. Light normalisation (case, n't expansion, plural/-ed/-ing stripping), "?" counts as a token.
(iii) NLI: SKIPPED. No transformers install and no cached NLI model; a download would add a dependency and needs a GPU lock; optional per task.
- Applied to: real-output mutants, real-output controls, the 200 unmutated originals, W-A injection identity/mutants, W-A challenge controls/mutants.
- Report mutation score and false-alarm rate per baseline per operator, with agreement vs judge. Overlap on W-A r1 challenges (no pair) is n/a.
