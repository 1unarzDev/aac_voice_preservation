## Headline: a measurement framework, a null result, and where it does not help

1. **Always-commit leaves silent reversals at roughly 24 (negation), 49 (politeness) and 162 (question/request) per 1,000 messages** (model-visible, 4-model mean; 95% CIs [16.0, 32.5], [38.5, 63.8], [134.1, 187.8]). Exposure (cue in the source, dropped from the keywords; model-independent upper bound) is 24, 56 and 277. Politeness and question/request rest on detector-proxy labels (provisional).
2. **No tested ask policy is distinguishable from gated-random at a 10% ask budget (100 asks per 1,000 messages).** None of the four pre-named primary contrasts is significant after Holm (smallest adjusted p = 1.00). Negation: prior vs gated-random -4.2 [-8.5, 2.2] per 1,000, which is smaller than the minimum detectable effect (8.5 per 1,000, section 4). The confidence signal is suggestive only (section 3).
3. **Probe beliefs are poorly calibrated against human base rates** (Brier skill score below 0 for every probe model on negation and politeness; section 5). This is a forced-choice acquiescence-confounded measure, not an AAC profile gap.
4. **Not delivered, stated plainly:** the closest-published-method benchmark (CLAM-style ambiguity classifier) was NOT implemented; the entropy policy is a stand-in and is not CLAM. The same-items G1 comparison is NOT available (G1 needs a spec; none exists for bare-keyword inputs). The chip and plain-word rows rest on a transported cue-honouring rate and assume that asking supplies the cue.

## 1. G1 (repair of the round-2 fatal defect)

**The round-2 claim 'G1 is harmful for politeness (measured)' is withdrawn.** It was a construction artefact: on bare-keyword inputs `interventions.supplied` returns an empty spec, and `interventions.check` then flags `politeness:added` on any polite output, so the flag is guaranteed by construction. It measured nothing about G1 as deployed. G1 is therefore **not applicable without a spec** and is excluded from every table of measured reversals below and from the figure.

- Bare keywords (flags by construction, not a G1 result): 176.8 flags per 1,000 outputs (HT), every one `politeness:added`, no flag names polarity or speech act.
- **Check with a real spec (option a, stored outputs, no generation).** The spec is the intent the user would have committed to: `supplied('The user typed: <source message>')`, i.e. oracle intent plus the keywords the model saw. Stored elic1 P0 outputs, all 4 models, 7,200 outputs, HT-weighted. This is an upper bound on G1 *detection*; repair requires regeneration, which was NOT run, so no repair rate is claimed.

| dimension | reversal outputs per 1,000 (output level) | of which flagged by check() per 1,000 | detection share | n reversal / n flagged |
|---|---|---|---|---|
| negation | 24.2 | 21.1 | 87% | 337 / 272 |
| politeness | 35.0 | 34.4 | 98% | 388 / 376 |
| question/request | 194.3 | 192.2 | 99% | 1166 / 1144 |

With that spec, check() also flags 41% of outputs that contain none of the three reversals (it checks agent, certainty, number and time too, so this is not a precision measure for the three dimensions) and flags `politeness:added` on 77.2 outputs per 1,000. These output-level rates use a different denominator from the unit-level model-visible reversals elsewhere in this report and are not comparable with them. Detection is not repair: whether regeneration after a flag restores the cue is an open question here.

**Hypothetical section (NOT measured).** If a spec-less G1 regenerated every flagged correct polite output into a non-polite one, it would create up to 100.6 silent politeness reversals per 1,000 outputs. This is arithmetic on flags that exist by construction, no regeneration was run, and it should not be read as a finding about G1.

## 4. Power: minimum detectable effect

MDE = 2.8 x bootstrap SE of the paired difference (80% power, two-sided 5%, normal approximation), model-visible, 10% budget.

|---|---|---|---|---|
| negation | prior - random_gated | 3.04 | 8.5 | 36% |
| negation | prior - conf_gated_mean | 3.18 | 8.9 | 37% |
| politeness | prior - random_gated | 5.29 | 14.8 | 30% |
| politeness | prior - conf_gated_mean | 6.02 | 16.9 | 34% |
| question/request | prior - random_gated | 5.38 | 15.1 | 9% |
| question/request | prior - conf_gated_mean | 6.23 | 17.4 | 11% |

For negation (76 exposure units out of 1800 keyword units) the MDE is about a third of the always-commit rate, so differences of the observed size are not detectable; a null here is **not** evidence of equivalence. The pre-declared TOST margins (5 / 10 / 25 per 1,000) are not met by any 90% CI, so the wording is 'not distinguishable', never 'equivalent'.

## 6. Where the methods do NOT help

- negation: at 10% asks, always-commit 23.9; prior 17.1 [10.0, 28.8], gated random 21.3, confidence 17.4. Not distinguishable.
- politeness: at 10% asks, always-commit 49.4; prior 38.1 [26.3, 53.4], gated random 43.7, confidence 44.8. Not distinguishable.
- question/request: at 10% asks, always-commit 161.9; prior 142.3 [115.5, 165.9], gated random 139.4, confidence 136.0. Not distinguishable.
- Question/request: 52 of 417 exposure units are unreachable by any gated policy; chip rho (0.79) and plain-word rho (0.87) are below 1, so prompting cannot fully repair this dimension even when asked. Labels provisional.
- H2 (weighting changes the ranking): not met (round 1, stored). H3: not testable by design for negation and politeness; the speech-act placebo fails (round 1, stored). H4 (prior >= 25% fewer reversals than confidence, CI excluding 0): not met; the '20% relative reduction' wording from round 2 is dropped (its CI includes 0).

## 7. Limitations and what was not done

- **CLAM-style comparator not implemented**; closest-published-method benchmark UNMET. The entropy policy is a stand-in. Implementing it needs about 10,800 local few-shot calls, which was not started because the owner's GPU pause (`GPU-PAUSE-NOTE.md`) asks that no new flock jobs start; the verbalized arm stalled on the shared endpoint (38 of about 1,700 keyword strings in round 2; below the declared 300-string floor, not used).
- Probe models: 3 of 5 (qwen2.5-14b, mistral-nemo-12b not run, queued job SIGSTOPped).
- Speech-act and politeness labels are detector proxies (provisional); `ANNOTATION_REQUEST.md` covers validation of both and the lexical gate; not sent.
- Chip and plain-word rows use transported rho and assume asking supplies the cue; G1 has no same-items measure.
- Human keyword sets only; 76 negation exposure units give low power (section 4). S3 RG/PPI and S4 DIF out of scope.
- The percentile point estimates of the refit prior are off-centre; read bootstrap mean and BC columns.
