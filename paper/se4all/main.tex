\begin{abstract}
Large language models (LLMs) let augmentative and alternative communication (AAC) apps expand a few selected words into a full sentence.
Such a feature can be fluent and still change what the person said: drop a refusal, change who acts, or add \say{please} to a deliberately plain request.
There is no single correct output, so the feature lacks testable requirements and a test oracle.
We specify \emph{commitment contracts}: input-conditioned requirements that state, per meaning dimension, what an expansion must preserve given what its input actually carried.
We test them with metamorphic relations over controlled input channels (a non-critical word must not change commitments; a cue must restore the cued commitment; a fully typed sentence must survive) and with a partial oracle that extracts labels blind to the input condition and computes verdicts deterministically.
An identity relation on the oracle itself exposed a specification defect, which we fixed.
In an audit of four models on \RES{n_fam_test} minimal-pair families, keywords that left polarity open were expanded to the affirmative in \pct{bare_pol_aff_p0} of greedy outputs, so a negated message always needed an extra input action.
One cue restored most commitments, but models still added politeness to plain sentences typed in full, while removing it rarely.
We derive requirements and test-design recommendations for AAC developers.
Human validation of the oracle is in progress. %CHECK
\end{abstract}

\section{Introduction}
%% =====================================================================
People who use AAC often compose a message by selecting a few words or symbols, because every selection costs time and effort~\cite{valencia2023less,cai2024speakfaster}.
Keyword expansion with an LLM is therefore attractive: from \kw{want go party} a model writes a complete sentence~\cite{shen2022kwickchat,cai2024speakfaster}.
This work is motivated by autistic AAC users,\footnote{We use identity-first language (\say{autistic person}), which many autistic adults prefer; individuals differ, and we respect their choices.} some of whom use AAC all the time and some only when speech is unavailable~\cite{zisk2019aac,donaldson2021everyone}.
For them, as for any AAC user, an expansion tool is a channel for self-expression.
If they refuse, speak directly, hedge, or ask rather than tell, those choices should arrive intact.
We do not assume an \say{autistic style} of language; we only require that choices which a person makes explicit are kept~\cite{frisch2026complicated}.

From a software-engineering view, the problem is that this requirement is rarely written down in a testable form.
Expansion has no single correct output, so exact-match tests are useless, and similarity metrics can miss a dropped negation~\cite{koch2022selfeval}.
This is the test-oracle problem in a setting where errors are easy to miss: \say{I want to go} is a fluent expansion of \kw{want go}, even when the person meant \say{I don't want to go}.
A second difficulty is that some errors are not the model's to avoid.
If compression removed \say{not}, no expander can recover it, and a test that fails the model for it measures the input design, not the model.

We treat meaning preservation in AAC expansion as an accessibility requirement that should be specified, tested, and regression-checked like any other.
Our key idea is to make each requirement \emph{conditional on the input}.
A \emph{commitment} is an explicit value of a message on one dimension, such as negated polarity or a plain (unsoftened) request.
A \emph{commitment contract} states what the output must preserve given which commitments the visible input carries, and it states where the input is ambiguous, so that a commitment there is recorded as a default rather than scored as a failure.

\paragraph*{Contributions}
\begin{enumerate}
\item \textbf{Commitment contracts and a channel-controlled harness} (\S\ref{sec:contracts}): executable, input-conditioned requirements for six dimensions, tested by metamorphic relations between controlled input channels of minimal-pair families.
\item \textbf{A partial test oracle} (\S\ref{sec:oracle}): label extraction that is blind to the input condition by construction, plus deterministic verdicts. A metamorphic relation on the oracle itself found and fixed a specification defect. Validation against human gold labels and authored challenge sentences is in progress; we state the acceptance criteria now. %CHECK
\item \textbf{An audit of four models} (\S\ref{sec:results}): systematic defaults under ambiguity, an asymmetry in which politeness is added to plain input far more often than removed, the weakest cues, and cue interaction and composition tests.
\item \textbf{Requirements and test-design recommendations} for teams building LLM features into AAC software (\S\ref{sec:recs}).
\end{enumerate}
We ran no study with AAC users, and we make no claims about benefit, effort or user preference.

\section{Related Work}
%% =====================================================================
\paragraph*{Testing ML and LLM systems}
CheckList organizes behavioral tests of NLP models as minimum-functionality, invariance and directional tests over linguistic capabilities, including negation and semantic roles~\cite{ribeiro2020checklist}.
Cho et al.\ catalogue 191 metamorphic relations for LLM-based NLP and evaluate 36 of them on three LLMs, framing them as a response to the oracle problem~\cite{cho2025metamorphic}.
COLLIE tests compositional constraints in text generation~\cite{yao2024collie}.
We borrow the invariance and directional patterns but condition them on a channel specification, so the expected relation depends on what the input carried.
LLM judges agree with people on many tasks but show position, verbosity and self-preference biases~\cite{zheng2023judging,panickssery2024selfpreference}, and learned similarity metrics can ignore negation~\cite{koch2022selfeval}.
We therefore restrict the judge to extraction, hide the condition from it, and validate it separately.
Prediction-powered inference shows how a small human-labeled sample can correct automated estimates~\cite{angelopoulos2023ppi}; our gold sample is drawn with known inclusion probabilities to permit such corrections.

\paragraph*{Accessibility in software engineering}
A systematic review of 94 studies treats accessibility across the whole development life cycle, not only as a final interface audit~\cite{paiva2021accessibility}.
Most accessibility testing checks whether an interface is perceivable and operable.
We test a different property of assistive software: whether its generated output keeps the user's meaning, which a conformance check cannot see.

\paragraph*{LLMs in AAC}
LLM expansion and suggestion tools for AAC include KWickChat~\cite{shen2022kwickchat}, SpeakFaster~\cite{cai2024speakfaster}, and systems studied with AAC users~\cite{valencia2023less}.
Several give users explicit control over intent: COMPA's intent buttons~\cite{valencia2024compa}, intention choices before expansion for people with aphasia~\cite{mao2025designprobes}, editable stance tags~\cite{xiang2025socializechat}, and personalization with clarification~\cite{pal2026spica}.
Choudhury et al.\ measure whether affect cues reach generated AAC sentences~\cite{choudhury2025alignment}; Lacosse et al.\ retain function words such as \say{not}~\cite{lacosse2026cognitivesteering}; and Gorenshtein et al.\ benchmark semantic drift, including negation and recipient probes, under simulated decoder errors~\cite{gorenshtein2026intentdrift}.
AAC users and practitioners raise authorship as a governance concern~\cite{griffiths2024consultation,griffiths2025authorship}.
Our contribution is not a new control or interface.
It is test design: requirements that separate what the input never carried from what the model changed, and an oracle whose own errors are tested.

\paragraph*{Dimensions and families}
We consider six dimensions: polarity, agent (who does the main action), certainty, speech act (statement, question, request, refusal, acceptance), politeness, and time or quantity.
A \emph{family} is a minimal pair of source messages that differ on exactly one critical dimension and share their content words, e.g., \say{I don't like the new medication} and \say{I like the new medication}.
Both map to the same \emph{bare} keywords (\kw{like medication}), so the bare input cannot distinguish them.
Each family also names one non-critical content word (\kw{new}) and, for each variant, the commitment \emph{chips} that disambiguate it (\chip{NOT}, \chip{YES}, \chip{?}, \chip{ASK}, \chip{TELL}, \chip{REFUSE}, \chip{MAYBE}, \chip{SURE}, \chip{I}, \chip{YOU}, \chip{PLEASE}, \chip{PLAIN}, and others).
Every variant needs at least one chip, so the unmarked reading also gets an explicit counter-chip and neither variant passes for free.
Chips are a test device for supplying a cue; they are not proposed here as an interface.

\paragraph*{Channels}
The harness renders every variant through five channels (Table~\ref{tab:channels}).
The channel fixes, by construction, which commitments the model received.
This separates three failure sources that a single fidelity score conflates: \emph{Loss} (the channel never carried the value), \emph{Violation} (the channel carried it and the output changed it), and \emph{Assumption} (the channel was ambiguous and the output committed anyway).
These are explanatory labels with separate denominators, not exclusive causes.

\paragraph*{Contract clauses}
For an output $y$ produced from input $x$ for variant $v$, let $L_d(y)$ be the extracted value on dimension $d$ and $C(x)$ the set of commitments that $x$ carries.
\begin{itemize}
\item[\textbf{R1}] \emph{Cue preservation.} If $C(x)$ fixes $d$ to $c$, then $L_d(y)=c$. A mismatch is a Violation.
\item[\textbf{R2}] \emph{Full-input preservation.} If $x$ is the full source, every explicit value of the source is kept, including the absence of politeness markers.
\item[\textbf{R3}] \emph{Ambiguity transparency.} If $C(x)$ does not fix $d$, $L_d(y)$ is not scored as pass or fail. Committed values are logged as Assumptions, and their distribution is reported per family, because a systematic default decides which reading the user gets for free.
\item[\textbf{R4}] \emph{Non-interference.} Adding a cue for dimension $e$ must not change a satisfied value on $d\neq e$.
\end{itemize}

\paragraph*{Metamorphic relations}
Each clause is tested by a relation between channels of the same variant, so most checks need no reference sentence.
\MR{1} (\emph{noncritical invariance}): adding the non-critical word must not change $L_d$; it also controls for input length when \MR{2} is evaluated.
\MR{2} (\emph{cue restoration}): adding the critical chip must move $L_d$ to the cued value (R1).
\MR{3} (\emph{full preservation}): with the full source, all values must match (R2).
\MR{4} (\emph{composition}): a cue that passes alone must still pass when a second, compatible cue is added (R4).
\MR{0} (\emph{oracle identity}): if the output repeats the source verbatim, the verdict must be pass. \MR{0} tests the oracle, not the model.
Relations are evaluated on extracted labels, never by string comparison, because LLM outputs vary from run to run (\S\ref{sec:threats}).

\section{A Partial Oracle}
\label{sec:oracle}
%% =====================================================================
The oracle is \emph{partial} by design.
It decides only whether explicit, text-level commitments are kept, from fixed option sets that always include \say{unclear/mixed}.
It does not judge fluency, appropriateness, or whether a user would accept the sentence.

\paragraph*{Blind extraction}
An extractor sees one output sentence and answers the family's critical question plus five general questions (polarity, speech act, agent, certainty, politeness).
It never sees the source, model, prompt, or channel.
A second pass shows the visible input and asks only whether the output adds a fact, reason, person, place, or time not in the input.
A codebook fixes edge cases before scoring: for example, \say{Can you\ldots?} alone is a request without a politeness marker, and \say{Can I\ldots?} is a question.
Identical texts are labeled once, whatever produced them, so the extractor cannot condition on the source of a text.
We use gpt-6.1-sol as extractor, a different model from the GPT model under test, with two prompt variants (J1, J2) that differ in wording, option order and item order.
Final labels require J1$=$J2; otherwise a cross-family arbiter decides.
In this run, \RES{n_j1_fallback} of \RES{n_rows_main} scored rows fell back to J1 because arbitration had not yet run.\pending{arbiter} %CHECK

\paragraph*{Deterministic verdicts}
Violation, Assumption and stance additions are computed by a short program from the extracted labels, the family specification and the channel (\S\ref{sec:contracts}).
Changing a contract rule therefore re-scores all outputs without new model calls, and every verdict can be traced to its labels.

\paragraph*{Testing the oracle}
We validate the oracle in three ways; only the first two are complete.
\emph{(i) Identity relation \MR{0}.} Of \RES{id_n} full-channel outputs that repeated the source verbatim (all prompts), the original oracle failed \RES{id_fail_raw}.
All \RES{id_fail_raw} were \say{acceptance} sources (\say{Yes, I'm joining the group chat.}) that the extractor labeled \say{statement}, which is also a correct description of that sentence. %CHECK
The fault was in our specification, not in the model under test: the two categories overlap, and the contract demanded a distinction the text does not force.
We changed the contract so that an acceptance target is satisfied by \say{acceptance} or \say{statement} (\RES{id_fail_fixed} identity failures remain); the original oracle stays reproducible for comparison. %CHECK
The fix makes the oracle more lenient: an acceptance that loses its \say{Yes} now passes, which we accept as a known blind spot.
\emph{(ii) Consistency.} J1 and J2 agreed at $\kappa=\RES{jj_kappa_crit}$ on the critical label over \RES{jj_n} units (lowest general dimension $\kappa=\RES{jj_kappa_min_general}$; added content $\kappa=\RES{jj_kappa_added}$).
This is reliability of one judge model under two prompts, not validity.
\emph{(iii) Human gold and challenge set.} Two coders independently label \RES{gold_n} held-out outputs from \RES{gold_fams} families, drawn with recorded inclusion probabilities, and \RES{challenge_n} authored challenge sentences (semantic mutations such as a dropped negation, and valid controls such as plain \say{Can you\ldots?}).
They see exactly what the extractor sees.

\section{Audit Setup}
%% =====================================================================
\paragraph*{Items}
The test set has \RES{n_fam_test} families, \RES{n_fam_dim} per dimension, written to a fixed specification and checked by an independent reviewer before generation. %CHECK
Prompts, codebook and rules were developed on \RES{n_fam_pilot} pilot and \RES{n_fam_dev} development families and frozen before the test run.
The items are constructed; they are not messages written by AAC users.
Ambiguity is not an artifact of our probes: on \RES{s1_n} crowd-written fictional AAC messages~\cite{vertanen2011imagination}, a content-word compressor dropped at least one explicit cue in \pct{s1_loss_excl_agent} of messages even when pronoun loss is ignored, by a rule-based detector. %CHECK

\paragraph*{Systems under test}
Three open models run locally with 4-bit quantization (Qwen2.5-7B-Instruct, Llama-3.1-8B-Instruct, Gemma-3-4B-it; GGUF Q4\_K\_M via llama.cpp) and one API model (gpt-6.1-terra).
All prompts describe the task as the sentence-composition feature of an AAC app and include the same chip legend.
P0 asks for one sentence, decoded greedily; P2 asks for three suggestions that \say{cover the different things the user might mean}; S3 draws three samples from P0 at temperature 0.7.
The main run has \RES{n_rows_main} scored rows from \RES{n_requests_main} requests and \RES{n_texts_main} distinct texts.
We report P0 unless stated.

\paragraph*{Follow-up experiments}
\emph{Exp B} (cue interaction and encoding) uses \RES{xb_n_fam} held-out politeness and speech-act families. It holds the critical chip fixed, crosses the presence of \chip{ASK} and \chip{YOU}, adds two inert spacer tags as a length control, and re-encodes the commitments as transparent aliases (\chip{NO-PLEASE}) or a natural-language \say{Meaning:} line.
\emph{Exp C} (composition) uses \RES{xc_n_fam} new families that cross \{\chip{YES},\chip{NOT}\} with \{\chip{I},\chip{YOU}\} in plain statements, giving neither, either, or both cues.
Both run greedy decoding twice under separate cache keys.

\paragraph*{Statistics}
Outputs within a family are dependent (both variants share a bare request).
Intervals are 95\% percentile intervals from 2,000 whole-family bootstrap resamples, and A/B-shared requests are counted once for defaults.
Follow-up experiments have few families; we report counts.

\section{Requirements and Test Design for AAC Practitioners}
\label{sec:recs}
%% =====================================================================

\paragraph*{Write requirements per dimension, conditional on input}
\say{Preserve the user's meaning} cannot be tested.
\say{If the input carries \chip{NOT}, the output is negated} can.
Write R1--R4 for each dimension your interface can express, and state where the input is ambiguous, so that tests do not blame the model for information the interface never collected.

\paragraph*{Test with minimal pairs and channel relations}
Use pairs that collide on the same keywords, and run every pair through bare, noncritical, cue and full channels.
The noncritical channel is the length control without which a cue's effect cannot be read.
Test invariance on individual outputs, not on aggregate rates.

\paragraph*{Test full-input preservation as a defect class}
An expander that edits a complete sentence is speaking in the person's place.
Treat added politeness, hedges or certainty on full input as a failing test, and make politeness assistance an opt-in setting.

\paragraph*{Test combinations of controls}
One chip passing alone does not mean it passes next to another; Exp~B found a control that broke when \chip{ASK} was added.
Include pairwise cue combinations and a length-matched inert control in the suite.

\paragraph*{Make defaults explicit}
Report, for each dimension, which reading the system produces from ambiguous input, and what the other reading costs.
A default that makes negation, questions or plain requests expensive is a product decision and should be documented and reviewed, preferably with AAC users.

\paragraph*{Test the oracle}
Keep extraction blind to the condition, compute verdicts in code, and run an identity relation and mutation probes against the oracle before trusting its fault counts.
Our identity relation found a contract defect that model-level tests had reported as model failures.

\paragraph*{Reuse the contracts at run time}
Because verdicts are computed from extracted labels, the same contracts can serve as a runtime monitor: an app can check a suggestion against the commitments the user entered and flag or regenerate it before it is spoken. Evaluating such a guard, including its latency and false alarms, is future work.

\paragraph*{Plan for nondeterminism}
Even at temperature 0, outputs differ between runs; compare labels, not strings, and repeat draws for any release gate.

\section{Threats to Validity and Limitations}
\label{sec:threats}
%% =====================================================================
\emph{No users.} We ran no study with AAC users or autistic people, so we cannot speak to benefit, effort, agency, or whether anyone wants a given output.
Commitments are text-explicit categories; we do not know any author's private intent.
\emph{Constructed and fictional text.} Probe families are authored, and the corpus estimate uses fictional crowd-written AAC messages with a rule-based detector~\cite{vertanen2011imagination}.
Neither shows what AAC users actually write or how often each dimension matters.
\emph{Oracle validity is pending.} The extractor is an LLM; J1/J2 agreement measures consistency, not correctness.
Until the human gold and challenge results are in, every rate above is conditional on the oracle, and \RES{n_j1_fallback} rows use a single prompt's label. %CHECK
The \MR{0} fix also makes the oracle more lenient for acceptances.
\emph{Nondeterminism.} Re-running identical greedy requests gave the same text in only \RES{nd_api_min}--\pct{nd_api_max} of cases for the API model and \RES{nd_local_min}--\pct{nd_local_max} for local models (Exp~B/C draws).
Our main run uses one cached draw; we repeated only the follow-up experiments. %CHECK
\emph{Scale.} Ten families per dimension and four models, three of them small and quantized, with fixed prompts and no conversation history, support statements about these systems and items, not population rates.
Follow-up experiments have four to eight families; their per-model results are counterexamples, not estimates.
\emph{Cost model.} One action per chip or keyword is a proxy; it omits reading suggestions, navigation and fatigue~\cite{frisch2026complicated}.

\section{Conclusion}
%% =====================================================================
Meaning preservation in LLM-based AAC can be specified and tested.
Conditioning requirements on the input separates what the interface never collected from what the model changed, and channel relations test it without reference sentences.
In our audit, one cue restored most commitments, but models defaulted to the affirmative, rewrote plain requests as polite ones even when typed in full, and had weak speech-act cues.
Testing the oracle mattered as much as testing the models.
We release the families, contracts, harness, oracle prompts and analysis code.\pending{repository URL}
