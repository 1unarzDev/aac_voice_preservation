\begin{abstract}
Given the complete typed sentence \say{Wear headphones for your music.}, an LLM sentence expander for augmentative and alternative communication (AAC) returned \say{Please wear headphones for your music.}
Across four models and \RES{pz_n_fam} authored directive families, fully typed plain sentences gained a politeness marker in \kof{p0_pz_added} cases, while polite ones lost theirs in \kof{p0_pz_removed}; per model, additions ranged from \kof{p0_pz_added_qwen} to \kof{p0_pz_added_gemma}, and an explicit preservation prompt changed the balance (\kof{p1_pz_added} vs.\ \kof{p1_pz_removed}).
Such failures are hard to test because expansion has no single correct output, and keywords often leave meaning open.
We write \emph{input-conditioned} preservation requirements: they score a commitment such as negation, a question, or plainness only when the input supplied it, and report the model's choice as a default when it did not.
Executable checks over controlled input channels, plus a partial oracle with blind extraction and code-computed verdicts, separate interface loss from model violation.
We also test the oracle: an identity check exposed a specification defect, and the obvious relaxation then missed keyed statement-substitution mutants, so the affected families are quarantined.
A developer can act on these checks: exact-copy routing passes all \RES{copy_pass_den} non-quarantined typed sources at zero model calls, and a runtime guard repairs \kof{g1_fix} supplied-cue failures, leaving \RES{g1_remain_k}.
All rates are machine-scored on constructed items, by an extractor whose labels agree with two human annotators at $\kappa=\RES{human_kappa_min}$--$\RES{human_kappa_max}$ on every label dimension, passing a pre-specified human gate.
\end{abstract}

\section{Introduction}
%% =====================================================================
People who use AAC often compose a message by selecting a few words or symbols, because every selection costs time and effort~\cite{valencia2023less,cai2024speakfaster}.
LLM keyword expansion turns such a selection into a full sentence~\cite{shen2022kwickchat,cai2024speakfaster}.
The same feature is sometimes given a sentence the person has already typed in full.
Fig.~\ref{fig:ratchet} shows what four models did then, on \RES{pz_n_fam} directive families written in plain and polite versions.
In \kof{p0_pz_added} plain cases the output added a marker such as \say{please}; the reverse happened in \kof{p0_pz_removed} (paired difference \RES{pz_full_asym} points \ci{pz_full_asym}).
The behavior is concentrated, not universal: Qwen added \kof{p0_pz_added_qwen}, Llama \kof{p0_pz_added_llama}, Gemma \kof{p0_pz_added_gemma}, and gpt-6.1-terra \kof{p0_pz_added_terra}.
It is also prompt-dependent: under a cached prompt that explicitly forbids added politeness, additions fell to \kof{p1_pz_added} but removals rose to \kof{p1_pz_removed}.

Adding \say{please} need not be an error in general; politeness suggestions can change how writers phrase messages and how they perceive a relationship~\cite{zhang2026politeness,chalfoun2025please}.
But here the person had already supplied the wording, so a system that rewrites it is speaking for them.
Contrast \kw{like medication}: these keywords do not say whether the person likes the medication, and every model chose the affirmative.
No model can be blamed for that guess, but the interface decides who has to pay an extra selection to say \say{don't}.
Testing such a feature therefore needs requirements that depend on what the input actually carried.

We treat meaning preservation in AAC expansion as an accessibility requirement that should be specified, tested and regression-checked.
We make three contributions.
(1)~\emph{Input-conditioned requirements} (\S\ref{sec:contracts}): executable checks that score a commitment only when the visible input supplied it, run over controlled input channels of minimal-pair families.
(2)~\emph{A partial oracle that is itself tested} (\S\ref{sec:oracle}), with a stated failure envelope, including a defect our own repair introduced, and validated against human labels on all \RES{human_gate_n} label dimensions.
(3)~\emph{A worked requirement $\to$ check $\to$ developer decision $\to$ failure envelope sequence} (\S\ref{sec:decisions}), including an evaluated runtime guard and an exact-copy baseline.
We ran no study with AAC users and make no claims about benefit, effort or preference.
All rates are machine-scored; the extractor behind them passed a pre-specified human-agreement gate on every label dimension (\S\ref{sec:oracle}).

\section{Related Work}
%% =====================================================================
\paragraph*{Testing LLM systems}
CheckList organizes behavioral tests into minimum-functionality, invariance and directional tests~\cite{ribeiro2020checklist}; Cho et al.\ catalogue metamorphic relations for LLM-based NLP~\cite{cho2025metamorphic}; COLLIE tests compositional generation constraints~\cite{yao2024collie}.
Sensei combines a conversational user simulator with a DSL for assertions and metamorphic relations, evaluated on seeded faults and deployed chatbots~\cite{delara2026sensei}.
Extracting fields, asserting properties and relating test cases are therefore established; we do not claim a new testing technique.
Our contribution is the AAC input specification: identical keywords for alternative readings, controlled cue availability, and separate treatment of lost information, violated supplied cues and defaults.
LLM judges show position, verbosity and self-preference biases~\cite{zheng2023judging,panickssery2024selfpreference}, and similarity metrics can miss negation~\cite{koch2022selfeval}; we restrict the judge to blind extraction and test it.

\paragraph*{LLMs in AAC}
Expansion and suggestion tools include KWickChat~\cite{shen2022kwickchat}, SpeakFaster~\cite{cai2024speakfaster} and systems studied with AAC users~\cite{valencia2023less}.
Several expose intent controls: intent buttons~\cite{valencia2024compa}, intention choices for people with aphasia~\cite{mao2025designprobes}, stance tags~\cite{xiang2025socializechat}.
Lacosse et al.\ keep bracketed function words such as \say{not} and evaluate semantic equivalence~\cite{lacosse2026cognitivesteering}; Choudhury et al.\ test whether affect cues reach the output~\cite{choudhury2025alignment}; Gorenshtein et al.\ benchmark intent drift, including negation, under simulated decoder errors~\cite{gorenshtein2026intentdrift}.
R-SPEAK was co-designed with people with aphasia and scores relevancy, faithfulness and completeness on real aphasic speech~\cite{altamimi2026rspeak}.
So AAC generation already has controls and fidelity evaluation; what we add is a conditional specification of \emph{which} commitments are testable under each input, and a test of the oracle.
Outside AAC, Navneet et al.\ show LLM rewriting can keep semantic similarity while erasing pragmatic markers, and that preservation prompts reduce but do not remove this~\cite{navneet2026voice}; our P1 sensitivity has the same shape.
Accessibility engineering spans the life cycle, not only interface audits~\cite{paiva2021accessibility}; conformance checks cannot see whether generated output keeps the user's meaning.

\section{Input-Conditioned Requirements}
\label{sec:contracts}
%% =====================================================================

\paragraph*{Families and channels}
A \emph{family} is a minimal pair of authored source messages that share content words and differ on one \emph{critical} dimension: polarity, agent (who acts), certainty, speech act, politeness, or time/quantity.
For example, \say{I don't like the new medication} and \say{I like the new medication} both compress to \kw{like medication}.
\RES{n_fam_quarantined} speech-act families (refusal/acceptance) also differ in polarity; they are quarantined from primary results (\S\ref{sec:oracle}).
Each variant is rendered through five channels (Fig.~\ref{fig:pipeline}): \emph{bare} keywords; \emph{noncrit}, which adds one family-specific content word (\kw{like new medication}); \emph{chip1}, which adds the critical cue as a bracketed tag (\chip{NOT}); \emph{chipall}, with every tag the variant needs; and \emph{full}, the source itself.
Every variant needs at least one tag, so the unmarked reading gets a counter-tag (e.g., \chip{PLAIN}) and neither variant passes for free.
Tags are a test device for supplying a cue, not a proposed interface.

\paragraph*{Requirements}
For output $y$ from input $x$ for variant $v$, let $L_d(y)$ be the extracted value on dimension $d$ and $C(x)$ the commitments $x$ carries.
\textbf{R1} (supplied cue): if $C(x)$ fixes $d$ to $c$, then $L_d(y)$ must be in the admissible set for $c$; otherwise it is a \emph{Violation}.
\textbf{R2} (full input): if $x$ is the full source, each scored explicit value of the source is kept, including the \emph{absence} of politeness markers.
\textbf{R3} (ambiguity): if $C(x)$ does not fix $d$, $L_d(y)$ is not pass/fail; a committed value is logged as an \emph{Assumption}, and its direction is reported, because a systematic default decides which reading is free.
\textbf{R4} (composition): adding a compatible cue for $e$ should not change a satisfied value on $d\neq e$.
R1, R2 and R4 concern commitments the input supplied.
R2's plainness clause is a software policy for typed text, not a claim about the author's private intent: absence of \say{please} may or may not be deliberate, and we only require that the system not change it unasked.
\emph{Loss} names the case in which a channel never carried the value.

\paragraph*{Executable checks}
\MR{2} (cue restoration) and \MR{3} (full preservation) are target-based contract checks on chip1/chipall and full outputs: they assert R1/R2 on a single output.
\MR{4} relates a single-cue output to a two-cue output and counts pass$\to$fail transitions (R4).
\MR{1} compares bare with noncrit.
Because both inputs leave $d$ open, a changed label is a \emph{default-sensitivity diagnostic}, not a defect; it also serves as a one-selection control when reading the cue effect.
Treating it as an invariance requirement would need extra applicability assumptions that some words violate (\say{weekend} and \say{tonight} carry time).
\MR{0} tests the oracle: an unchanged source must pass.
\paragraph*{What the conditioning changes}
A reference-fidelity score compares each output with its authored source.
It would fail \say{I like medication} against \say{I don't like the new medication} although the keywords never carried the negation; our checks record it as an Assumption and charge the interface, not the model (E1).
Conversely, a similarity score would rate \say{Please wear headphones for your music.} as close to the typed sentence; R2 fails it because the input supplied the plain wording (E3).
The same output can thus be a default under one channel and a violation under another, which is the distinction a developer needs before deciding what to fix.

With a balanced pair, any bare-channel output matches at most one of the two variants, so 50\% is a design ceiling for paired match, not a target or a prior over real intentions.

The oracle decides only whether a fixed set of explicit, text-level values is kept.
It does not judge fluency, appropriateness, referents or whether anyone would accept the sentence.

\paragraph*{Pipeline as run}
An extractor (gpt-6.1-sol, a different model from the GPT model under test) sees one output and answers the family's critical question plus five general questions; it never sees source, model, prompt or channel.
Two prompt variants (J1, J2) differ in wording, option order and item order.
Critical labels are resolved once per unit (text, visible input, dimension) and shared across runs: a cross-family arbiter (claude-opus-5-5) decides J1/J2 disagreements, otherwise the agreed label wins, otherwise the label is unknown; there is no single-prompt fallback.
The arbiter sees the output, the codebook and the visible input, so for arbitrated full-channel units it is not blind to the source; this is a disclosed exception to blind extraction.
In the main run \RES{n_arbiter_rows} scored rows (\RES{n_arbiter_units} units) were arbitrated and \RES{n_unknown_rows} remain unknown.
General-dimension disagreements are broken by a rule-based extractor (layer0), which the guard in \S\ref{sec:decisions} also uses; this shared component limits their independence.
Verdicts are computed by code from labels, the item specification and the channel, so a rule change re-scores all outputs without model calls.

\paragraph*{A defect found, a repair, and its blind spot}
Before these injections, the identity relation run on stored model outputs found that the original oracle failed \RES{id_fail_raw} of \RES{id_n} case- and punctuation-normalized reproductions of the source, all on one sentence, \say{Yes, you can borrow my car this weekend}, coded \emph{statement} against the target \emph{acceptance} (E10 in Table~\ref{tab:examples}).
The categories overlap, so the contract demanded a distinction the text need not force.
We relaxed the rule so that \emph{statement} satisfies an acceptance target.
The keyed challenges then showed the cost: the relaxed oracle detects \kof{or_acc_mut_det} acceptance mutants and misses both statement substitutions (\say{You borrowed my car this weekend.}), whereas the raw rule detects \kof{or_new_mut_det_raw} new mutants.
Fixing a false alarm removed fault sensitivity.
We therefore quarantine both refusal/acceptance families from every primary result (leaving \RES{n_fam_primary} of \RES{n_fam_test} families) and report them only as sensitivity.
A symmetric acceptance/refusal predicate remains open.

\subsection{Channel attribution (R1, R3)}

Fig.~\ref{fig:ladder} separates the two kinds of evidence.
Under bare input, every greedy polarity output was affirmative (\kof{bare_pol_aff_p0}); certainty outputs were unhedged in \kof{bare_modeshare_cer} committed cases, and the speaker was the agent in \kof{bare_modeshare_agt}.
These are Assumptions (R3), not failures.
Asking for three different meanings (P2) produced both polarity readings in only \kof{covk_p2_pol} suggestion sets.
Adding the noncritical word left the critical label unchanged in \kof{mr1_crit} aligned outputs (\kof{mr1_crit_ntq} without the time/quantity families, whose added words can carry time); as a default-sensitivity diagnostic this shows that defaults are unstable, not that the model erred.

Once supplied, cues mostly worked.
Critical match rose from \kof{cm_noncrit} (noncrit) to \kof{cm_chip1} with one tag, \kof{cm_chipall} with all tags and \kof{cm_full} with full input; all \RES{pol_neg_chip1_den} negated targets were negated with \chip{NOT}.

\section{From Requirement to Developer Decision}
\label{sec:decisions}
%% =====================================================================
Table~\ref{tab:decisions} shows how each requirement becomes a check, what the check found, what a developer could decide, and what the evidence does not cover.



The full-mode row is the clearest engineering lesson.
If an interface lets the person say \say{this is my sentence}, the requirement is met by not generating at all; the remaining question is a product one, whether full mode is offered and discoverable.
The guard row shows that the same requirements can run at run time, with measured repairs, residual failures and cost.
The oracle row shows why the checks need their own regression tests: our first repair silently weakened them.

\paragraph*{Recommendations}
Write each requirement conditional on the input and per dimension; \say{preserve meaning} is not testable, \say{if the input carries \chip{NOT}, the output is negated} is.
Test with minimal pairs, report joint as well as focal preservation, and keep defaults separate from failures.
Treat added politeness or certainty on full input as a failing test and make style assistance opt-in.
Give the oracle identity and keyed-mutation tests, and re-run them after every relaxation.
Compare labels, not strings, and repeat draws for any release gate.

\section{Threats to Validity}
\label{sec:threats}
%% =====================================================================
\emph{Construct.} Labels are coarse, text-explicit categories from a codebook; \say{plain} means no explicit marker, and coverage of content, referents, negation scope and certainty degree (emphatic outputs pass a plain target by design) is partial.
\emph{Oracle.} All rates depend on an LLM extractor; it passed the human gate, but with two annotators, near-ceiling agreement and a codebook written for explicit markers, the validation covers these dimensions on these outputs, not subtler readings; machine-panel agreement shares errors.
\emph{Selection and scale.} Ten authored families per dimension and four fixed models support counterexamples and regression tests, not prevalence; examples were selected after discovery, by declared rules.
The politeness asymmetry is prompt-dependent (P1) and model-dependent.
\emph{Follow-ups.} Composition evidence uses eight scenarios and a tag that models literalize.
\emph{Cost.} Selection counts omit reading, navigation and fatigue~\cite{frisch2026complicated}.
\emph{Serving.} Guard latency used a local server with partial CPU offload and is not a deployment estimate.
\emph{No users.} We cannot speak to benefit, agency or whether anyone wants a given output; we do not assume an \say{autistic style} of language~\cite{zisk2019aac,donaldson2021everyone}.

\section{Conclusion}
%% =====================================================================
Even a sentence the person typed in full can come back changed.
Conditioning requirements on what the input carried separates that violation from the guesses an interface forces when it collects less, and turns both into executable checks with a developer decision attached.
Testing the oracle mattered as much as testing the models: a repair that removed false alarms also removed fault sensitivity.
We release the families, requirements, harness, oracle tests, stored outputs and analysis code.\pending{repository URL / release snapshot}
