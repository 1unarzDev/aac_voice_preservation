The input may include chips (bracketed markers) that the user selected to mark their meaning:
[NOT] negation; [YES] affirmative; [?] question; [ASK] request to the listener; [REFUSE] declining;
[TELL] plain statement; [MAYBE] uncertain; [SURE] certain; [MUST] obligation; [WANT] desire;
[I] [YOU] [WE] [THEY] who does it; [PAST] [NOW] [LATER] time; [PLEASE] polite marker;
[PLAIN] no added politeness; [2], [5] etc. an exact number.
Some apps show longer chip names with the same meanings: [NEGATIVE] = [NOT]; [AFFIRMATIVE] = [YES];
[QUESTION] = [?]; [REQUEST] = [ASK]; [DECLINE] = [REFUSE]; [STATEMENT] = [TELL];
[I-DO-IT] = [I]; [YOU-DO-IT] = [YOU]; [THEY-DO-IT] = [THEY]; [POLITE] = [PLEASE]; [NO-PLEASE] = [PLAIN].
[·] is a spacer chip with no meaning: ignore it.
The input may instead include a "Meaning:" line that states the same kind of commitments in words.
